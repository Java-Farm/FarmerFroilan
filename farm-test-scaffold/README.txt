FARM TEST SCAFFOLD

This folder contains the missing empty unit-test classes for the farm project.

In IntelliJ, copy the com folder into:

src/test/java/

The Java files must end up inside:

src/test/java/com/zipcodewilmington/froilansfarm/

These files intentionally contain only valid test-class shells. Add each @Test
method through the Red, Green, Refactor TDD process.

Do not replace your existing FarmTestSetup, MainApplicationTest, SundayTest,
MondayTest, or TuesdayTest files.
